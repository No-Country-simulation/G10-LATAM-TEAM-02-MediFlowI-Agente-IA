## ⚡ Nomenclatura y Automatización de Archivos PR

La regla de nomenclatura para los archivos de Pull Request en la carpeta `Docs/` es:
> `Docs/PULL_REQUEST_AAAA-MM-DD_PR[N].md`

Donde:
- `AAAA-MM-DD` es la fecha de generación obtenida automáticamente del sistema.
- `PR[N]` es el identificador del PR (`PR1`, `PR2`, `PR3`, etc.).

Para solicitar un nuevo PR al Agente IA:
> *"Generar PR para Autor: [Nombre del Autor]"*

El Agente IA tomará la fecha del sistema, creará el archivo con la nomenclatura `Docs/PULL_REQUEST_AAAA-MM-DD_PR[N].md` basándose en la plantilla [`Docs/PLANTILLA_PULL_REQUEST.md`](file:///c:/proyectos_git_parionayauricasa/G10-LATAM-TEAM-02-MediFlowI-Agente-IA/Docs/PLANTILLA_PULL_REQUEST.md) y actualizará este índice maestro [`Docs/PULL_REQUEST.md`](file:///c:/proyectos_git_parionayauricasa/G10-LATAM-TEAM-02-MediFlowI-Agente-IA/Docs/PULL_REQUEST.md).
