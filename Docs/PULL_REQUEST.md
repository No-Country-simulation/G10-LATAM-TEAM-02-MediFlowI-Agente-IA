## ⚡ Automatización para Generar Nuevos PRs

Para documentar los Pull Requests de la jornada actual, solo se requiere solicitar:
> *"Generar PR para Autor: [Nombre del Autor]"*

El Agente IA tomará **automáticamente la fecha actual del sistema** (`AAAA-MM-DD`), cargará la plantilla [`Docs/PLANTILLA_PULL_REQUEST.md`](file:///c:/proyectos_git_parionayauricasa/G10-LATAM-TEAM-02-MediFlowI-Agente-IA/Docs/PLANTILLA_PULL_REQUEST.md), creará o actualizará el archivo diario `Docs/PULL_REQUEST_AAAA-MM-DD.md` (agregando correlativamente `PR #1`, `PR #2`, etc.) y actualizará este índice maestro `Docs/PULL_REQUEST.md`.
