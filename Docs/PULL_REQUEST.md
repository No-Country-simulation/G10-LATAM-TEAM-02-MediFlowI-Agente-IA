## ⚡ Nomenclatura y Automatización de Archivos PR

La regla de nomenclatura para los archivos de Pull Request en la carpeta `Docs/pull_requests/` es:
> `Docs/pull_requests/PULL_REQUEST_AAAA-MM-DD_PR[N].md`

Donde:
- `AAAA-MM-DD` es la fecha del sistema tomada automáticamente.
- `PR[N]` es el identificador correlativo (`PR1`, `PR2`, `PR3`, etc.).

Para solicitar un nuevo PR al Agente IA:
> *"genera pr"* (o *"genera pr para autor [Nombre]"*)

El Agente IA tomará la fecha del sistema, detectará la secuencia del día, creará el archivo `Docs/pull_requests/PULL_REQUEST_AAAA-MM-DD_PR[N].md` basado en [`Docs/PLANTILLA_PULL_REQUEST.md`](file:///c:/proyectos_git_parionayauricasa/G10-LATAM-TEAM-02-MediFlowI-Agente-IA/Docs/PLANTILLA_PULL_REQUEST.md), lo **vinculará explícitamente con su respectivo `HISTORIAL_CAMBIOS_AAAA-MM-DD_CAMBIO[N].md`** y actualizará este índice maestro [`Docs/PULL_REQUEST.md`](file:///c:/proyectos_git_parionayauricasa/G10-LATAM-TEAM-02-MediFlowI-Agente-IA/Docs/PULL_REQUEST.md).
